# **Calculadora 2º Semestre Engenharia da Computação**

Esse é o primeiro projeto do curso de Engenharia da Computação. O objetivo desse projeto é desenvolver uma calculadora científica para que além de cálculos simples seja personalizada.

# **Desafio**

O desafio desse projeto consiste em desenvolver uma calculadora científica que além de cálculos seja capaz de realizar cálculos mais complexos, assim auxiliando profissionais e estudantes das áreas de Engenharia.
